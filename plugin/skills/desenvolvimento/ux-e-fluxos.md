# UX e fluxos de trabalho

Use quando o pedido envolver navegação, usabilidade, formulários, páginas, permissões, tarefas repetitivas ou reorganização de uma interface.

## Método
1. Identifique os usuários/perfis reais, tarefa principal, frequência de uso e dados que precisam consultar ou editar. Não invente pesquisa com usuários; trate hipóteses como hipóteses.
2. Mapeie o caminho mínimo para concluir cada tarefa, os pontos de erro e as decisões importantes. Preserve caminhos conhecidos, a menos que exista benefício claro.
3. Priorize a ação mais comum por tela; informações e ações secundárias devem continuar descobríveis, mas não competir com a principal.
4. Para dados administrativos, decida entre tabela, formulário, resumo, gráficos ou cartões conforme o objetivo: comparação e edição frequente normalmente favorecem tabelas; visão geral favorece poucos indicadores.
5. Especifique busca, filtros, ordenação, paginação quando necessária, feedback, confirmação de ações destrutivas, permissões, telas vazias, carregamento e erros.
6. Reduza cliques e trabalho repetitivo sem ocultar informações essenciais nem adicionar atalhos confusos.

## Critérios de aceite
- O usuário sabe onde está, o que pode fazer e o que aconteceu após cada ação.
- A tarefa principal ficou mais fácil de realizar; o ganho é descrito de maneira verificável.
- Não se criaram páginas, menus ou indicadores apenas para preencher espaço.
