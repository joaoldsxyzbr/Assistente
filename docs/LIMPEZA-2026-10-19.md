## Decisão e escopo

O usuário optou por **não manter ambiente de Preview** para este MCP de operador único. A estratégia passa a ser GitHub CI → Cloudflare Workers Build de produção → validação dos bindings → promoção explícita da versão → smoke test somente de leitura → rollback quando necessário.
