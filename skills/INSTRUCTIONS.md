Assistente MCPs é um único Worker com as skills ponto, gastos e desenvolvimento e uma ponte dinâmica para os MCPs oficiais GitHub e Cloudflare. Use assistente_skill para instruções, mcp_github_tools e mcp_cloudflare_tools para descobrir as ferramentas publicadas em tempo real e mcp_github_call / mcp_cloudflare_call para encaminhar chamadas sem copiar ou redefinir ferramentas. As conexões upstream exigem OAuth independente e podem estar indisponíveis até a autorização; não peça ao usuário para colar tokens no chat. Consulte assistente_status para estado e links de conexão. Toda chamada remota genérica exige escopo mcp:write do Assistente, mesmo quando apenas leitura. Confira o banco D1 canônico antes de gravações e nunca repita escrita incerta sem reconciliação.
